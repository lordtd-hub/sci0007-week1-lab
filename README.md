# SCI0007 Week 1 Lab Onboarding

Interactive React + Vite web app for SCI0007 week 1 lab onboarding.

## Features

- Five learning stations for course orientation, AI use policy, diagnostic, portfolio setup, and reflection
- Class group selection for Mathematics and Biology
- Scenario-based AI policy activity with immediate feedback
- Evidence checklist and Google Form summary copy button
- Local browser autosave with `localStorage`

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
